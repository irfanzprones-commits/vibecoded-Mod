# Mod Hub

Static GitHub Pages website for showcasing and downloading your mods.

## Edit
- Open `data/mods.json`
- Replace `YOUR_GITHUB_USERNAME` with your GitHub username
- Change the mod list, versions, descriptions, and changelogs

## Publish on GitHub Pages
1. Push these files to your repository
2. Open **Settings → Pages**
3. Choose your branch and root folder
4. Save

## Download links
Buttons point to:
`https://github.com/YOUR_GITHUB_USERNAME/REPO/releases/tag/VERSION`

You can change the release link logic in `index.html` if you want a different format.
