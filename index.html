GitHub Pages setup

Use this in your repository.

1. Upload these files to your repo.
2. Go to Settings → Pages.
3. Choose the branch and root folder.
4. Save and wait for the site URL.
Download buttons use GitHub Releases. Replace YOUR_GITHUB_USERNAME in data/mods.json with your username.
